# Thirties Documentation Archive

Historical documents, kept for lineage only. **Do not use anything here as an active plan, requirement or source of truth.** Much of it was written in loosely supervised planning sessions and contradicts `AGENTS.md` in places (for example, fixed "creative work in daylight, admin in dark" rules). Where it disagrees with `AGENTS.md`, `AGENTS.md` is right.

- `mvp_design_doc.md`: the original application spec and domain model design from project inception.
- `EVAL_HARNESS_SPEC.md`: the original spec for large-scale synthetic evaluation.
- `REARCHITECTURE_ACTION_PLAN.md`: the plan for moving from legacy shims to the generic block primitives (completed).
- `BRANCH_STRATEGY_PRACTICAL.md`: the design doc of the former `feat/practical-gemini-assistant` branch. Still useful as a reference for the Joplin sync-note payload (§3) and the Telegram bridge commands (§5.3).
- `BRANCH_STRATEGY_SLM.md`: the design doc of the former `feat/longterm-slm-architecture` branch. Its still-valid ideas (event spans, backlog pre-scoring, eval reconciliation) now live in `../ROADMAP.md` and `../SLM_BRAIN.md`.

Raw evaluation reports and session databases from October 9–10, 2026 were removed from the tree. They remain in git history: see commit `5effc38` (`docs/archive/eval_reports/`).
