# Thirties Documentation Archive

The files in this directory represent historical architectural specifications, initial phase planning documents, and earlier design drafts:

- `mvp_design_doc.md`: The initial application specification and domain model design document written at project inception.
- `EVAL_HARNESS_SPEC.md`: The initial evaluation harness specification for large-scale synthetic testing.
- `REARCHITECTURE_ACTION_PLAN.md`: The intermediate action plan used to transition from legacy shims to universal orthogonal primitives.
- `eval_reports/`: Raw JSONL logs and markdown evaluation summaries generated during earlier testing rounds.

> **CRITICAL DIRECTIVE FOR FUTURE SESSIONS**:
> **DO NOT** use the documents in this `archive/` folder as active plans, requirements, or current architectural sources of truth.
> The primary, authoritative source of truth for architecture, engineering philosophy, and active roadmap is always **`docs/BRANCH_STRATEGY_AND_DESIGN.md`** on your current git branch.
